# DS4002-CS3
Crop Type and Disease Classification Case Study by Livvy Yurish

## Repository Contents
- [Data folder](https://github.com/lyurish00/DS4002-CS3/tree/main/Data): This folder contains a PDF with instructions on how to access the data.
- [Materials folder](https://github.com/lyurish00/DS4002-CS3/tree/main/Materials): The folder contains all of the materials needed for this case study, including the following:
  - [ds4002_case_study.ipynb](https://github.com/lyurish00/DS4002-CS3/blob/main/Materials/ds4002_case_study.ipynb) is the starter code for this case study. Use this as a guide to unzip the data, create a workable dataset, train and test random forest, and evaluate and improve the model. 
  - [Random_Forest_for_Image_Classification.pdf](https://github.com/lyurish00/DS4002-CS3/blob/main/Materials/Random_Forest_for_Image_Classification.pdf): Random forest for image classification code explaination from GeeksforGeeks.  
  - [Random_Forest_Algorithm_for_Crop_Disease_Detection.pdf](https://github.com/lyurish00/DS4002-CS3/blob/main/Materials/Random_Forest_Algorithm_for_Crop_Disease_Detection.pdf): Scholarly article detailing a random forest algorithm that can classify crop diseases. 
- [Hook.pdf](https://github.com/lyurish00/DS4002-CS3/blob/main/Hook.pdf): The PDF of the hook document for this case study.
- [LICENSE](https://github.com/lyurish00/DS4002-CS3/blob/main/LICENSE): Describes how the content in this repository can be used.
- README.md: This file.
- [Rubric.pdf](https://github.com/lyurish00/DS4002-CS3/blob/main/Rubric.pdf): The PDF of the rubric for this case study.
