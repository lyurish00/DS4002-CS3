# DS4002-CS3
Crop Type and Disease Classification Case Study by Livvy Yurish

## Repository Contents
- Data folder: This folder contains a PDF with instructions on how to access the data.
- Materials folder: The folder contains all of the materials needed for this case study, including the following:
  - ds4002_case_study.ipynb is the starter code for this case study. Use this as a guide to unzip the data, create a workable dataset, train and test random forest, and evaluate and improve the model. 
  - Random Forest article
  - Crop disease classifcation article
- Hook.pdf: The PDF of the hook document for this case study. 
- Rubric.pdf: The PDF of the rubric for this case study.
